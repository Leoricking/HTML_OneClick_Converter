# HTML 一鍵轉換器／網頁剪藏 v2.5.15

適用於 Chromium 架構瀏覽器：

- Google Chrome
- Microsoft Edge
- Opera

## v2.5.15：修正背景截圖頻率超過瀏覽器限制

- 瀏覽器拒絕背景 DevTools 截圖時，`captureVisibleTab` 備援會以佇列序列化，每次至少間隔 600 ms，避免超過 Chromium 每秒截圖次數限制。
- 遇到瀏覽器回報截圖頻率限制時延長退避時間再試，不會因短時間連續請求立即取消整個長截圖。
- 新增並行請求間隔測試；保留 v2.5.14 的 104 頁尾空拼接修正。

## v2.5.14：修正 104 頁尾 4099／4068 px 空拼接段

- 當頁面上限回報 4099 px、實際只能停在 4068 px，且已拼接高度等於實際畫面底端（4800 px）時，略過不含新像素的第 10 段。
- 僅在確認已到頁尾、已覆蓋至實際畫面底端，且差值不超過 64 px 時，才按已覆蓋高度修整多出的尾端；尾端未覆蓋時仍拒絕輸出。
- 新增 4099／4068／4800／732 px 的精確回歸案例，涵蓋可略過與不可略過兩種情況。

## v2.5.13：處理擷取途中頁面高度縮短

- 擷取期間若頁面高度縮短，最後位置會以瀏覽器目前回報的頁尾為準，不再沿用已過期的預估位置（例如要求 4580 px、即時上限 4099 px）。
- 只有在實際已到新頁尾，且已拼接覆蓋新頁面高度時，才裁掉頁面縮短後不存在的尾端；未覆蓋到新頁尾仍取消下載，避免缺資料。
- 若頁面提早抵達即時底部，停止重複擷取舊的預估段落；保留分段圖片與缺列檢查。

## v2.5.12：修正長頁第 10 段拼接位置中斷

- 每段改依「已覆蓋的實際像素」計算下一個捲動位置，避免前幾段的捲動短差逐段累積，造成最後一段落在已覆蓋範圍之外。
- 最後一段重新對齊目前頁尾；錯誤提示會列出要求位置、實際位置、已覆蓋高度與視窗高度，方便定位未預期的瀏覽器捲動限制。
- 保留重疊取樣、逐段覆蓋檢查與空白缺列保護；新增累積偏移回歸測試。

## v2.5.11：修正 104 頁面第 9 段捲動差 28 px 中止

- 針對 104 職缺頁的 4096 px 目標、4068 px 實際停留位置，容許最多 64 px 的穩定短差；不限於已抵達頁尾的情況。
- 短差必須確實向前移動，拼接使用瀏覽器回報的實際停留位置；未移動而重複同一畫面、或短差超過 64 px，仍會停止，避免漏列或重複拼接。
- 新增測試涵蓋 104 回報的 4096/4068 px、中途頁面高度變動，以及同畫面未前進仍須拒絕的案例。

## v2.5.10：修正瀏覽器回報捲動上限但實際位置短少 31 px

- 修正頁面回報可捲到 4003 px、實際穩定停在 3972 px 時仍被判定為捲動失敗的條件；v2.5.9 只接受「實際位置等於回報上限」的情況，沒有涵蓋附件中的現象。
- 只在目標已接近目前頁尾、實際位置穩定且差距不超過 64 px 時接受；中途卡住或頁尾差異超過 64 px 仍會停止，避免把重複畫面當作成功。
- 新增回歸測試，驗證頁尾上限回報正確與回報偏大的 4003/3972 px 案例。

## v2.5.9：依即時頁尾判斷捲動差，不依預估段數

- 頁尾容差依目前的捲動上限和實際位置判斷，不再依賴預先估算的「最後一段」；頁面高度在擷取中變動時仍可正確識別已抵達實際底部。
- 4003 px 要求、3972 px 上限的 31 px 差距會通過頁尾檢查；中途捲動停住或差距超過 64 px 仍會停止。
- 只有確認抵達實際頁尾且文件高度差與捲動差相符時，才裁掉空白尾端，不縮放已擷取像素。

## v2.5.8：修正頁尾差 31 px 時中止

- 最後一段要求位置超過即時捲動上限最多 64 px 時，不再被前置的 24 px 範圍檢查擋下；只有確認已到實際頁尾才套用容差。
- 要求 4003 px、實際上限 3972 px 這類頁尾差異，會依目前頁高收斂輸出，裁掉對應的空尾端，不縮放已擷取像素。
- 若差距超過 64 px、中途停住，或頁面高度變化與頁尾差異不符，仍會中止並提示，避免輸出缺資料的圖片。

## v2.5.7：修正分頁拒絕背景連接，靜態頁擷取加速

- 若瀏覽器允許 debugger 背景擷取，切換分頁仍會持續擷取來源頁。
- 若網站或瀏覽器拒絕背景連接（例如 `Cannot attach to this target`），改用可見分頁截圖；使用者切到別頁時工作會暫停，不會誤抓其他分頁或取消，切回來源頁後自動續跑。此備援模式需要來源頁保持在原瀏覽器視窗的前景分頁。
- 經可逆探測確認靜態的頁面，每段繪製等待縮至 110 ms；動態或無法確認的頁面由 350 ms 降為 260 ms，保留原本重疊拼接及完整性檢查。

## v2.5.6：切換分頁不中斷、104 頁面加速與頁尾容差

- 整頁截圖工作嘗試暫時連接來源分頁的 Chromium 截圖通道；能連接時切換到其他分頁仍擷取原來源頁，完成或失敗會解除連接。擴充功能新增 `debugger` 權限，重新載入時瀏覽器會顯示權限提示。
- 一般頁面捲動改為直接定位並驗證位置，省去每一小段的平滑動畫等待；每段仍等待頁面繪製並使用重疊拼接。
- 快速頁面探測忽略 sticky 樣式屬性的變化，但若文字或節點有更新仍退回小步距；表格、Grid、Canvas、內部捲動及 Garmin 頁面維持保守流程。
- 頁尾捲動取整差在 24 px 內時，文件頁會用來源頁的實際頁面座標補擷取尾端像素；若補擷取失敗或內部捲動頁仍有缺口，會取消下載，不會用複製像素掩蓋缺圖。

## v2.5.5：靜態頁面加速並保留動態資料頁品質

- 擷取前以可還原的短距離捲動檢查頁面；只有沒有表格、Canvas、內部捲動器、已知 Garmin 頁面且檢查期間 DOM 沒有變動時，才使用約 70% 視窗高度的步距。
- Garmin、表格／Grid、Canvas、內部捲動及任何無法確認的頁面，維持 v2.5.4 的小步距、重疊拼接、位置確認與完整性檢查。
- 快速步距仍保留約 30% 畫面重疊；第一段完整保留視窗內容，拼接覆蓋檢查不變。探測後會回到頁首再正式擷取。
- 這是減少截圖段數的加速；實際速度取決於網站重繪與瀏覽器截圖速度。無法確認為靜態頁面時會自動走保守流程。

## v2.5.4：修正頁尾差幾個像素就中止並縮短等待

- 接近頁面底部時容許最多 24 px 的瀏覽器捲動取整差異，並以實際捲動位置拼接，避免頁面要求 3978 px、實際只能到 3972 px 時整個任務失敗。
- 每段截圖後固定等待由 650 ms 降為 350 ms；仍保留小步距與重疊區，降低動態表格漏列風險。
- 側欄擷取同樣採用較短等待；原有自動重試、記憶體釋放、分段下載與完整性檢查保留。

## v2.5.3：長時間截圖自動重試

- 完整頁面截圖每段增加截圖節流間隔；遇到暫時性瀏覽器擷取錯誤時最多自動重試 6 次，不會第一次失敗就整個中斷。
- 長圖改為逐段壓縮並釋放畫布，控制高解析度截圖的記憶體用量，避免累積數百段時因畫布占用過高而中止。
- 重試期間會在「擷取完整網頁」按鈕下方顯示目前段落與重試進度。
- 原有超長頁面分段下載與逐段下載進度保留。

## v2.5.2：超長頁面分段下載與醒目結果提示

- 超出單張 Canvas 高度或面積限制時，改為維持原解析度分成多張垂直長圖，自動逐張下載；不再因整張過大而直接取消。
- 每張檔名標記「完整網頁_第001部分」等序號，方便依序檢視與合併。
- 將進度、成功及錯誤提示放在「擷取完整網頁」按鈕正下方的醒目狀態區。
- 超寬到單張 Canvas 無法承載的頁面仍會明確提示；這種情況請改用 PDF。

## v2.5.1：修正完整頁面截圖看起來沒有反應

- 將進度列與狀態訊息移到圖片擷取按鈕下方，啟動、進度、成功或錯誤都能在操作位置直接看到。
- 分頁查詢、截圖程式注入及啟動訊息加入逾時與錯誤回報，避免按鈕停在無訊息狀態。
- 完整頁面分段捲動、拼接及自動下載流程保留。

## v2.5.0：改用窄條逐段拼接完整頁面

- 將捲動步距縮小到視窗高度約 16%（每次最多 180 CSS px），降低虛擬化表格跳過尚未繪出的列的機會。
- 每次只把長圖尚未覆蓋的畫面條帶寫入，後續截圖不會覆蓋已完成區域，也不會把滾動中的空白列覆寫到先前有效的資料。
- 加入拼接覆蓋高度檢查；若中間段落未完整接上，取消下載並顯示錯誤，避免把不完整長圖當成成功結果。
- 側欄獨立拼接、背景下載及原捲動位置還原保留。

## v2.4.9：完整頁面截圖不再隱藏網頁元素

- 完全取消依元素定位方式隱藏固定元件的步驟，避免 Garmin 等頁面把虛擬化資料列誤判成浮動 UI，造成列號跳過或中間空白。
- 完整頁面仍以重疊分段捲動截圖，固定側欄仍分開拼接；固定工具列可能在接縫重複，但保留頁面資料優先。
- 保留截圖完成後還原原始捲動位置與背景自動下載。

## v2.4.8：避免固定元件誤判隱藏資料

- 移除依靠小幅捲動座標推測固定元件的流程；巢狀捲動頁面中，圖表、卡片與虛擬表格列可能不隨主捲動區移動，先前會被誤當成浮動元件隱藏。
- 拼接時只處理明確標示為 fixed 且面積較小的介面元件；保留 sticky 元素、表格、圖表、圖片及含資料的區塊。
- 保留約 30% 重疊截圖、固定側欄獨立拼接、背景自動下載與原捲動位置還原。

## v2.4.7：降低動態表格在截圖接縫漏列

- 完整頁面截圖改以約 70% 視窗高度作為捲動步距，讓相鄰截圖片段保留約 30% 重疊。
- 重疊區由後一張截圖片段覆蓋，降低 Garmin 等動態表格在捲動重繪時漏掉列資料的情況。
- 固定側欄獨立拼接、原頁捲動位置還原與背景自動下載維持原流程。

## v2.4.6：修正固定側欄文字消失

- 拼接時保護側欄、側欄子元素及包住側欄的固定外層容器，避免固定元件去重把整個 Garmin 左側導覽列一起隱藏。
- 將側欄區域狀態提升至截圖工作範圍，確保成功與失敗時都能還原側欄捲動位置。
- 保留原本側欄獨立拼接、主頁分段捲動與背景自動下載流程。

## v2.4.5：修正側欄拼接偏移與裁切

- 主頁長圖先獨立拼接，再以側欄自己的捲動範圍從頂端擷取側欄，避免主頁與側欄捲動距離不同造成空白、偏移或裁切。
- 側欄內容只依自身高度拼接一次；超出側欄內容的長圖區域保留原側欄底色，不重複控制項。
- 擷取結束後還原主頁與側欄的原始捲動位置。

## v2.4.4：完整拼接可捲動的左側欄

- 偵測固定側欄內部可捲動區，擷取時讓側欄內容依長圖垂直位置同步移動，避免左欄只顯示第一個畫面或重複相同控制項。
- 側欄內容超出其實際高度後保留底色；完成或失敗時都還原側欄原本捲動位置。
- 靜態側欄仍只出現一次；一般頁面分段捲動、固定導覽列去重與背景自動下載維持不變。

## v2.4.3：修正完整頁面擷取無反應

- 修正建立長圖畫布時先讀取、後宣告固定側欄區域，導致擷取工作立即中止且介面沒有進度的錯誤。
- 將側欄偵測與區域初始化提前至畫布繪製前；既有逐段捲動、側欄只出現一次與自動下載流程保留。

## v2.4.2：固定側欄只保留一次

- 整頁截圖第一段保留固定側欄完整 UI；後續捲動段不再重複側欄，只延續側欄底色並拼接主內容。
- 修正 v2.4.1 保留整個固定側欄子樹後，造成左側欄位每個畫面分段重複出現的問題。

## v2.4.1：修正側欄內部控制項在長截圖消失

- 偵測固定側欄根節點，拼接時同時保留側欄與其所有子元素，避免側欄外框存在但欄位／按鈕被單獨隱藏。
- 這是 v2.4.0 側欄保留修正的補強版；固定側欄仍會隨每段畫面重複顯示。

## v2.4.0：保留固定側欄並改善 OneNote 圖片清晰度

- 整頁截圖拼接時保留貼齊視窗左右邊緣的固定側欄，避免長圖中段側欄空白；側欄會隨每個畫面分段重複顯示。
- 選取區域先以 PNG 無損擷取；複製到 OneNote 剪貼簿或透過 Graph 建立頁面時，固定使用原像素 PNG，不因 JPG 選項而先壓縮。
- JPG 選項只套用在下載檔案；OneNote 貼上及直接建立頁面維持 PNG。沒有縮放選取圖片的像素尺寸。
- OneNote 仍可能依自身顯示縮放或影像最佳化設定改變畫面觀感；建議以 OneNote「另存圖片」後比對像素尺寸，並確認頁面縮放比例。

## v2.3.9：補強受限捲動頁面的完整截圖

- 捲動容器偵測新增 `overflow-y: hidden`，支援由網頁程式控制捲動位置的 SPA 頁面。
- 每段截圖前確認實際捲動位置已到達目標；如果頁面不動或捲動範圍中途改變，會停止並顯示原因，不會把重複畫面當成完整頁面下載。
- 進度顯示採用整頁或內部捲動區、可捲動距離與分段數。

## v2.3.8：恢復可見的逐段捲動

- 完整頁面截圖改為逐段平滑捲動原網頁，確認位置穩定後才擷取該段。
- 擴充功能視窗可收起；網頁仍會顯示實際捲動與截圖進度，完成後自動下載。

## v2.3.7：修正長圖資料傳送與自動下載

- 完整頁面長圖以 512 KiB 區塊傳送到下載背景程序，避免一次傳送大型圖片資料失敗。
- 背景程序確認圖片資料完整後才啟動下載；傳送或下載失敗會顯示具體錯誤，不會回報完成。
- 維持 v2.3.6 的分頁背景捲動與逐段截圖；關閉擴充功能視窗後仍會繼續執行。

## v2.3.6：完整頁面截圖改為背景執行

- 點擊「擷取完整網頁」後，捲動、分段截圖與拼接改由網頁中的擴充功能內容程序執行，不依賴擴充功能彈出視窗存活。
- 可在截圖途中關閉擴充功能視窗；原網頁保持開啟時，程序會繼續執行並自動下載 PNG/JPG 長圖。
- 進度仍會顯示在彈出視窗；若切換到其他分頁，會停止並提示保持原頁面在前景，以免拼接到錯誤頁面。
- 完成或失敗時都會還原網頁原本的捲動位置與固定導覽列顯示狀態。

## v2.3.5：修正目前畫面截圖

- 目前畫面與整頁截圖統一使用 Chromium callback／Promise 相容呼叫，避免不同 Chromium 瀏覽器的 API 回傳方式造成按鈕一直停在處理狀態。
- 截圖與下載加入逾時及錯誤提示；若瀏覽器未授予目前分頁截圖權限，提示重新開啟擴充功能後再試。
- 不新增網站存取權限；截圖仍由使用者點擊擴充功能按鈕後執行。

## 網頁剪藏格式

新增完整的本機網頁剪藏模組：

1. **整篇文章 HTML（保留排版）**
   - 自動分析 `article`、`main`、`role=main`、文章內容區等候選節點。
   - 保留主要文字、圖片、表格、連結及基本排版。
2. **簡化文章 HTML**
   - 移除導覽、表單、嵌入物件、多餘 class／style，輸出乾淨閱讀版。
3. **完整頁面 MHTML**
   - 使用 Chromium `pageCapture.saveAsMHTML` 封裝頁面及瀏覽器可取得的圖片、CSS 等資源。
   - 同步下載剪藏資訊 TXT，保存標題、網址、下載分類、標籤與備註。
4. **完整頁面 HTML 快照**
   - 保存目前 DOM 狀態並將相對網址轉成可解析的來源網址。
   - 為安全起見移除 script、iframe、object、embed 與表單。
5. **書籤卡片 HTML**
   - 保存標題、網址、網站圖示、下載分類、標籤、備註與剪藏時間。
6. **手動點選網頁元素 HTML**
   - 回到網頁後移動滑鼠會顯示綠色選取框。
   - 點一下鎖定元素，再由網頁上方工具列儲存、重新選擇或取消。
7. **拖曳選取區域截圖**
   - 回到網頁後拖曳選取範圍，依圖片設定輸出 PNG 或 JPG。
   - 同步產生剪藏資訊 TXT；按 `Esc` 取消。
8. **剪藏整理欄位**
   - 剪藏標題、下載分類、標籤與備註。
   - 下載分類會轉成瀏覽器資料夾：`HTML網頁剪藏/<下載分類>/`。
9. **傳送到 OneNote**
   - 目的地可選「下載＋傳送到 OneNote」、「只傳送到 OneNote」或「只下載」。
   - 智慧文章、簡化文章、完整 HTML、書籤與選取元素會以 HTML 富文字寫入剪貼簿。
   - 區域截圖會以 PNG 圖片寫入剪貼簿；到 OneNote 按 `Ctrl+V` 即可。
   - MHTML 選擇 OneNote 時會改用可貼上的完整 HTML 版；選擇兩者時，同時下載 MHTML 並傳送可編輯完整頁面版。

> 剪貼簿模式不會上傳內容。直接建頁模式只會將使用者主動剪藏的內容傳送至 Microsoft Graph／OneNote。

## 主要功能

1. **網頁剪藏**
   - 智慧文章、簡化文章、MHTML、HTML 快照、書籤、元素選取與區域截圖。
2. **另存目前網頁 PDF**
   - 開啟瀏覽器列印視窗並選擇「另存為 PDF」。
3. **擷取目前畫面 PNG / JPG**
   - 儲存目前分頁可見範圍。
4. **擷取完整網頁 PNG / JPG**
   - 自動捲動頁面。
   - 分段截圖後拼接成完整長圖。

5. **下載主要內容 TXT**

   - 圖片下載至 `HTML轉圖片`。

2. 開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」。

4. 選擇本專案資料夾。

### Opera

1. 開啟 `opera://extensions/`
2. 開啟「開發人員模式」。

## 使用

1. 開啟要轉換的網頁或本機 HTML。
2. 點工具列上的「HTML 一鍵轉換器」圖示。
3. 若要使用網頁剪藏，先設定：
   - 剪藏標題
   - 剪藏格式
   - 輸出目的地（下載、OneNote 或兩者）
   - OneNote 傳送方式（剪貼簿或直接建頁）
   - 下載分類
   - 標籤
   - 備註
4. 可先按「預覽剪藏效果」，確認原網頁上的藍色選取範圍。
5. 按「開始剪藏」。選取元素或區域截圖模式會回到網頁等待操作。
6. 其他既有功能可直接選擇：
   - 另存目前網頁 PDF
   - 擷取目前畫面
   - 擷取完整網頁
   - 下載主要內容 TXT
   - 下載全部文字 TXT
   - 複製主要內容
   - 複製到 OneNote（20pt）
7. 檔案會直接進入瀏覽器預設下載資料夾。

## OneNote 直接建頁：第一次設定

直接建頁需要你自己的 Microsoft Entra 應用程式 Client ID。這是 Microsoft 對第三方 OneNote 工具的安全要求。

1. 前往 [Microsoft Entra 管理中心](https://entra.microsoft.com/)，開啟「應用程式註冊」。
2. 建立新註冊，帳戶類型建議選擇「任何組織目錄中的帳戶及個人 Microsoft 帳戶」。
3. 在「驗證」新增 **Single-page application（SPA）** 平台。
4. 從擴充功能的「Redirect URI」欄位複製完整網址，加入 SPA Redirect URI。
5. 在「API 權限」加入 Microsoft Graph 的委派權限 `Notes.ReadWrite`。
6. 複製「應用程式（用戶端）識別碼」，貼入擴充功能的 Client ID 欄位。
7. 按「登入 Microsoft」，同意權限後選擇 OneNote 筆記本與節區。

本擴充功能使用 PKCE，不需要也不接受 Client Secret。若重新安裝後擴充功能 ID 改變，請把畫面顯示的新 Redirect URI 加到 Entra 應用程式。

## 已知限制

- `chrome://`、`edge://`、`opera://`、擴充功能商店等受保護頁面不能擷取純文字。
- 可見畫面截圖通常仍可用於部分受保護頁面，但不同瀏覽器政策可能不同。
- 超長或超寬頁面可能超過 Canvas 尺寸／記憶體限制。
- 動態載入頁面建議先捲到最底再回到原處，讓內容載入完成後執行整頁截圖。
- 影片、WebGL、跨來源 iframe、持續動畫或虛擬清單可能無法完整拼接。
- HTML 快照不能保證離線載入所有跨來源資源；需要完整封裝時優先使用 MHTML。
- MHTML 實際包含的資源取決於 Chromium 當下已載入且允許保存的內容。
- 選取區域截圖只能擷取目前可見範圍；整個長頁請使用「擷取完整網頁」。
- 整頁截圖期間請不要切換分頁或關閉彈出視窗。
- 瀏覽器頁面縮放會影響輸出解析度；超長頁面可先調低縮放比例。
- OneNote 20pt 貼上效果依 OneNote 版本而略有差異，但支援 HTML 貼上的版本通常可保留字級。
- 網頁剪藏貼到 OneNote 時，外部圖片能否載入取決於原網站權限與 OneNote 版本；文字、連結與基本排版仍可貼入。
- 直接建頁依賴 Microsoft Graph、Microsoft 帳號與網路連線；公司租戶可能要求管理員同意 `Notes.ReadWrite`。
- OneNote API 不支援背景服務帳號；直接建頁一定由目前登入的 Microsoft 使用者授權。
- 一般筆記本節區可直接選取；節區群組內的巢狀節區目前未列入選單。

## 權限說明

- `activeTab`：只在使用者點擊擴充功能後存取目前分頁。
- `scripting`：擷取頁面文字、取得尺寸及控制捲動。
- `downloads`：將 PNG / JPG / HTML / MHTML / PDF / TXT 寫入下載資料夾。
- `storage`：記住中繼資料、圖片格式及網頁剪藏偏好。
- `pageCapture`：由 Chromium 產生完整頁面 MHTML 封裝檔。
- `clipboardWrite`：在使用者選擇 OneNote 目的地時，寫入富文字或 PNG 圖片剪貼簿。
- `identity`：開啟 Microsoft 登入視窗並接收 OAuth 重新導向結果。
- `https://login.microsoftonline.com/*`：交換及更新 Microsoft OAuth 權杖。
- `https://graph.microsoft.com/*`：讀取使用者授權的 OneNote 筆記本／節區，並建立剪藏頁面。

本版本不使用自建遠端伺服器。只有選擇「直接建立頁面」時，才會把本次剪藏內容傳送至 Microsoft Graph／OneNote。
