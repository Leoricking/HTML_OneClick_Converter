# HTML 一鍵轉換器／網頁剪藏 v2.3.4

適用於 Chromium 架構瀏覽器：

- Google Chrome
- Microsoft Edge
- Opera

## v2.3.0：簡化閱讀選取剪藏與整篇文章剪藏

- 簡化閱讀模式的「複製選取內容」「儲存選取內容」只處理閱讀預覽中反白的範圍。
- 新增「剪藏整篇文章」，需要完整內容時可獨立使用，不受目前反白範圍影響。
- 在簡化閱讀模式按「預覽剪藏效果」或「開始剪藏」會先開啟可捲動、可反白的閱讀預覽。
- 「整篇文章 HTML（保留排版）」是獨立的完整文章剪藏格式。

## v2.2.0：互動式元素選取與簡化閱讀預覽

1. **元素先鎖定、再儲存**
   - 滑鼠移動時顯示選取框，點一下只會鎖定元素，不會立刻消失。
   - 網頁上方會顯示「儲存剪藏／重新選擇／取消」工具列。
   - 直接在網頁工具列儲存，不需要重新打開擴充功能。
2. **真正的簡化閱讀預覽**
   - 在原網頁上顯示乾淨、可捲動的閱讀版面，不只是顯示範圍框。
   - 預覽中的文字可以反白、按 `Ctrl+C`，連結與圖片也會保留。
   - 提供「複製選取內容」「儲存選取內容」「剪藏整篇文章」「關閉」按鈕。
   - 選取內容會寫入 HTML 富文字與純文字，可直接貼到 OneNote。

## v2.1.0：OneNote 雙模式與剪藏預覽

1. **OneNote 剪貼簿模式**
   - 不需登入 Microsoft；完成後切換到 OneNote 按 `Ctrl+V`。
2. **OneNote 直接建頁模式**
   - 以 Microsoft OAuth 2.0 Authorization Code + PKCE 登入，不使用 Client Secret。
   - 可選擇帳號內的 OneNote 筆記本與節區，按「開始剪藏」後直接建立新頁面。
3. **原網頁剪藏預覽**
   - 按「預覽剪藏效果」會在原網頁標示擷取範圍；切換剪藏格式時同步更新。

## 網頁剪藏格式

新增完整的本機網頁剪藏模組：

1. **整篇文章 HTML（保留排版）**
   - 自動分析 `article`、`main`、`role=main`、文章內容區等候選節點。
   - 保留主要文字、圖片、表格、連結及基本排版。
2. **簡化文章 HTML**
   - 移除導覽、表單、嵌入物件、多餘 class／style，輸出乾淨閱讀版。
3. **完整頁面 MHTML**
   - 使用 Chromium `pageCapture.saveAsMHTML` 封裝頁面及瀏覽器可取得的圖片、CSS 等資源。
   - 同步下載剪藏資訊 TXT，保存標題、網址、下載分類、標籤與備註。
4. **完整頁面 HTML 快照**
   - 保存目前 DOM 狀態並將相對網址轉成可解析的來源網址。
   - 為安全起見移除 script、iframe、object、embed 與表單。
5. **書籤卡片 HTML**
   - 保存標題、網址、網站圖示、下載分類、標籤、備註與剪藏時間。
6. **手動點選網頁元素 HTML**
   - 回到網頁後移動滑鼠會顯示綠色選取框。
   - 點一下鎖定元素，再由網頁上方工具列儲存、重新選擇或取消。
7. **拖曳選取區域截圖**
   - 回到網頁後拖曳選取範圍，依圖片設定輸出 PNG 或 JPG。
   - 同步產生剪藏資訊 TXT；按 `Esc` 取消。
8. **剪藏整理欄位**
   - 剪藏標題、下載分類、標籤與備註。
   - 下載分類會轉成瀏覽器資料夾：`HTML網頁剪藏/<下載分類>/`。
9. **傳送到 OneNote**
   - 目的地可選「下載＋傳送到 OneNote」、「只傳送到 OneNote」或「只下載」。
   - 智慧文章、簡化文章、完整 HTML、書籤與選取元素會以 HTML 富文字寫入剪貼簿。
   - 區域截圖會以 PNG 圖片寫入剪貼簿；到 OneNote 按 `Ctrl+V` 即可。
   - MHTML 選擇 OneNote 時會改用可貼上的完整 HTML 版；選擇兩者時，同時下載 MHTML 並傳送可編輯完整頁面版。

> 剪貼簿模式不會上傳內容。直接建頁模式只會將使用者主動剪藏的內容傳送至 Microsoft Graph／OneNote。

## v1.4.0 修正

1. **修正 Garmin Connect 等網站只能截到目前畫面**
   - 自動判斷網頁是由整個視窗捲動，還是由頁面內的大型容器捲動。
   - 支援採用 `overflow: auto` / `overflow: scroll` 的 SPA、儀表板及後台網站。
   - 依內部容器的完整 `scrollHeight` 計算輸出高度並分段捲動拼接。
   - 內部容器模式下，左側選單、頂部工具列及黏著標題只保留一次。
   - 截圖結束或失敗後，會還原視窗與內部容器原本的捲動位置。

## v1.3.0 修正

1. **修正整頁長截圖重複出現網站標題列／導覽列**
   - 第一段保留網站原本的標題列。
   - 第二段開始自動隱藏固定及黏著式浮動元件，避免每個拼接處重複。
   - 除了 CSS `fixed` / `sticky`，也會以短距離捲動前後的位置比對，偵測由外層容器、transform 或 JavaScript 實作的固定導覽列。
   - 每一段都會重新掃描，支援 104 人力銀行等會在捲動時動態重建導覽列的網站。
   - 完成或失敗後都會還原元素與原本捲動位置。

## v1.1.0 新增功能

1. **圖片格式可選 PNG / JPG**
   - 目前畫面截圖支援 PNG 與 JPG。
   - 完整網頁長圖也支援 PNG 與 JPG。
   - JPG 會以較小檔案體積輸出。
2. **新增「複製到 OneNote（20pt）」**
   - 將主要文字內容複製成可貼到 OneNote 的格式。
   - 貼到 OneNote 後會保留 **20pt 字體大小**。
   - 若瀏覽器不支援 HTML 剪貼簿，會自動退回一般純文字複製。


## v1.2.0 新增功能

1. **另存目前網頁 PDF**
   - 一鍵開啟目前網頁的列印視窗。
   - 在「目的地」選擇「另存為 PDF」即可輸出。
   - 可使用列印視窗調整紙張方向、邊界、縮放與背景圖形。
   - 受 Chromium 安全限制，擴充功能不能略過列印視窗直接靜默儲存 PDF。

## 主要功能

1. **網頁剪藏**
   - 智慧文章、簡化文章、MHTML、HTML 快照、書籤、元素選取與區域截圖。
2. **另存目前網頁 PDF**
   - 開啟瀏覽器列印視窗並選擇「另存為 PDF」。
3. **擷取目前畫面 PNG / JPG**
   - 儲存目前分頁可見範圍。
4. **擷取完整網頁 PNG / JPG**
   - 自動捲動頁面。
   - 分段截圖後拼接成完整長圖。
   - 完成後還原原本捲動位置。
   - 第二段開始隱藏 CSS fixed / sticky 及實際黏在視窗上的浮動元件，避免導覽列重複出現。
5. **下載主要內容 TXT**
   - 優先尋找 `article`、`main`、`role=main` 等主要內容區域。
6. **下載全部文字 TXT**
   - 使用頁面 `body.innerText`，保留所有可見文字。
7. **複製主要內容**
   - 可直接貼到 ChatGPT、記事本、Word 等。
8. **複製到 OneNote（20pt）**
   - 以 HTML + 純文字雙格式寫入剪貼簿。
9. **TXT 中繼資料**
   - 可選擇是否加入標題、網址與擷取時間。
10. **安全檔名**
   - 自動移除 Windows 不允許的檔名字元。
11. **自動分類**
   - 圖片下載至 `HTML轉圖片`。
   - 文字下載至 `HTML轉文字`。
   - 網頁剪藏下載至 `HTML網頁剪藏/<下載分類>`。

## 安裝

### Chrome

1. 開啟 `chrome://extensions/`
2. 開啟右上角「開發人員模式」。
3. 按「載入未封裝項目」。
4. 選擇解壓後的 `HTML_OneClick_Converter` 資料夾。
5. 將擴充功能固定到工具列。

### Edge

1. 開啟 `edge://extensions/`
2. 開啟「開發人員模式」。
3. 按「載入解壓縮」。
4. 選擇本專案資料夾。

### Opera

1. 開啟 `opera://extensions/`
2. 開啟「開發人員模式」。
3. 按「載入未封裝的擴充功能」。
4. 選擇本專案資料夾。

## 使用

1. 開啟要轉換的網頁或本機 HTML。
2. 點工具列上的「HTML 一鍵轉換器」圖示。
3. 若要使用網頁剪藏，先設定：
   - 剪藏標題
   - 剪藏格式
   - 輸出目的地（下載、OneNote 或兩者）
   - OneNote 傳送方式（剪貼簿或直接建頁）
   - 下載分類
   - 標籤
   - 備註
4. 可先按「預覽剪藏效果」，確認原網頁上的藍色選取範圍。
5. 按「開始剪藏」。選取元素或區域截圖模式會回到網頁等待操作。
6. 其他既有功能可直接選擇：
   - 另存目前網頁 PDF
   - 擷取目前畫面
   - 擷取完整網頁
   - 下載主要內容 TXT
   - 下載全部文字 TXT
   - 複製主要內容
   - 複製到 OneNote（20pt）
7. 檔案會直接進入瀏覽器預設下載資料夾。

## OneNote 直接建頁：第一次設定

直接建頁需要你自己的 Microsoft Entra 應用程式 Client ID。這是 Microsoft 對第三方 OneNote 工具的安全要求。

1. 前往 [Microsoft Entra 管理中心](https://entra.microsoft.com/)，開啟「應用程式註冊」。
2. 建立新註冊，帳戶類型建議選擇「任何組織目錄中的帳戶及個人 Microsoft 帳戶」。
3. 在「驗證」新增 **Single-page application（SPA）** 平台。
4. 從擴充功能的「Redirect URI」欄位複製完整網址，加入 SPA Redirect URI。
5. 在「API 權限」加入 Microsoft Graph 的委派權限 `Notes.ReadWrite`。
6. 複製「應用程式（用戶端）識別碼」，貼入擴充功能的 Client ID 欄位。
7. 按「登入 Microsoft」，同意權限後選擇 OneNote 筆記本與節區。

本擴充功能使用 PKCE，不需要也不接受 Client Secret。若重新安裝後擴充功能 ID 改變，請把畫面顯示的新 Redirect URI 加到 Entra 應用程式。

## 本機 HTML 注意事項

若要處理 `file:///...` 本機 HTML：

1. 在擴充功能管理頁找到本擴充功能。
2. 開啟「允許存取檔案網址」。
3. 重新開啟本機 HTML 後再操作。

## 已知限制

- `chrome://`、`edge://`、`opera://`、擴充功能商店等受保護頁面不能擷取純文字。
- 可見畫面截圖通常仍可用於部分受保護頁面，但不同瀏覽器政策可能不同。
- 超長或超寬頁面可能超過 Canvas 尺寸／記憶體限制。
- 動態載入頁面建議先捲到最底再回到原處，讓內容載入完成後執行整頁截圖。
- 影片、WebGL、跨來源 iframe、持續動畫或虛擬清單可能無法完整拼接。
- HTML 快照不能保證離線載入所有跨來源資源；需要完整封裝時優先使用 MHTML。
- MHTML 實際包含的資源取決於 Chromium 當下已載入且允許保存的內容。
- 選取區域截圖只能擷取目前可見範圍；整個長頁請使用「擷取完整網頁」。
- 整頁截圖期間請不要切換分頁或關閉彈出視窗。
- 瀏覽器頁面縮放會影響輸出解析度；超長頁面可先調低縮放比例。
- OneNote 20pt 貼上效果依 OneNote 版本而略有差異，但支援 HTML 貼上的版本通常可保留字級。
- 網頁剪藏貼到 OneNote 時，外部圖片能否載入取決於原網站權限與 OneNote 版本；文字、連結與基本排版仍可貼入。
- 直接建頁依賴 Microsoft Graph、Microsoft 帳號與網路連線；公司租戶可能要求管理員同意 `Notes.ReadWrite`。
- OneNote API 不支援背景服務帳號；直接建頁一定由目前登入的 Microsoft 使用者授權。
- 一般筆記本節區可直接選取；節區群組內的巢狀節區目前未列入選單。

## 權限說明

- `activeTab`：只在使用者點擊擴充功能後存取目前分頁。
- `scripting`：擷取頁面文字、取得尺寸及控制捲動。
- `downloads`：將 PNG / JPG / HTML / MHTML / PDF / TXT 寫入下載資料夾。
- `storage`：記住中繼資料、圖片格式及網頁剪藏偏好。
- `pageCapture`：由 Chromium 產生完整頁面 MHTML 封裝檔。
- `clipboardWrite`：在使用者選擇 OneNote 目的地時，寫入富文字或 PNG 圖片剪貼簿。
- `identity`：開啟 Microsoft 登入視窗並接收 OAuth 重新導向結果。
- `https://login.microsoftonline.com/*`：交換及更新 Microsoft OAuth 權杖。
- `https://graph.microsoft.com/*`：讀取使用者授權的 OneNote 筆記本／節區，並建立剪藏頁面。

本版本不使用自建遠端伺服器。只有選擇「直接建立頁面」時，才會把本次剪藏內容傳送至 Microsoft Graph／OneNote。
